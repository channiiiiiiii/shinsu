## 원본 출처

`src/shisu/domain/legacy/{pet,species,shop,farming,adventure}.py`는 2026-09-15 로컬 DAMAGOCHI 스냅샷에 웹 연결 수정을 더한 코드다. 보스·종족 기본값, EXP 공식, 장비 비용은 유지한다. 공통 웹 전투는 `domain/combat.py`에 구현했다.

## 해석상 제한

이 표는 구현 연결 상태다. 사용자가 수동 검증을 담당하므로 전체 완료 테스트 통과를 의미하지 않는다. 신화·고대 신규 던전 배율과 공통 웹 전투 밸런스, 모든 조건 조합, 실제 Supabase 연결 및 운영 세이브 이전은 사용자 확인이 남아 있다. 기존 Discord 전투와 결과가 동일하다는 보장은 하지 않는다.
