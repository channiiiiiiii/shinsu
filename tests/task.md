# 검증 목표

- 해제 후 보석 수량 보존·전투 스탯 감소·재장착과 출처별 수치 합계 일치를 검증한다.

- 재배포를 반복해도 기린 변경 revision이 한 번만 증가하고 변경 전 세이브가 남는지 검증한다.

- 관리자 종족 변경 후 이름·레벨·재화·속성·보물 강화도 보존을 검증한다.

- 라이브 UI 변경 후 정적 자원 확인과 기존 API 회귀 테스트를 유지한다.
